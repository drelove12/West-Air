WESTERN AIR — GITHUB PAGES SETUP

EASIEST METHOD: This version is a SINGLE HTML FILE. No assets folder needed.

1. Extract the ZIP.
2. Open your GitHub repository and go to the Code tab.
3. Select Add file > Upload files.
4. Upload index.html (not the ZIP itself). Place it in the repository root, not in a subfolder.
5. Commit changes.
6. In Settings > Pages, choose Deploy from a branch, branch main, folder /(root), then Save.
7. Wait a few minutes and visit https://YOUR-USERNAME.github.io/YOUR-REPO/

To preview offline, double-click index.html in the extracted folder.

To activate the Join button, edit index.html and find YOUR_EMAIL@example.com; replace it with your real email. You can also edit recruitmentLink in the embedded script at the end of the file to a Discord invitation URL.

If the site still appears plain, ensure the new index.html replaced the old one, then hard-refresh with Ctrl+Shift+R.
